## Key Hardware Features Visible in Photos

- **Bottom (Photo 1)**: Lower chassis base plate, front steering linkage, rear differential assembly, and drive shaft output couplers.
- **Right Side (Photo 2)**: Parallel steering linkage, motor driver board, power distribution wiring, and side sensor positioning.
- **Rear / Back (Photo 3)**: Rear drive motor assembly, gearing mounts, and cell battery pack housing.
- **Front (Photo 4)**: Camera mount housing the Raspberry Pi Camera Module 3 positioned at the top deck for vision line-of-sight, alongside front distance sensors.
- **Top (Photo 5)**: Raspberry Pi 5 computation unit, power management board, custom battery tray, and wiring routing gaps between decks.
- **Left Side (Photo 6)**: Two-level modular chassis design separating computational electronics (top deck) from mechanical motor/drivetrain components (bottom deck).
